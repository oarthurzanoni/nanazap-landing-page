# NanaZap Landing Page

The public landing page for NanaZap, a WhatsApp campaign and messaging product.

## Project goal

Present the product proposition, its main workflows and its visual identity through a fast, responsive static website that can be deployed with minimal infrastructure.

## Features

- Responsive product presentation
- Feature and workflow sections
- Custom visual assets and styling
- Deployment through GitHub Pages with a custom domain

## Technologies

- **HTML**
- **CSS**
- **JavaScript**
- **GitHub Pages**

## What I learned

- Translating a SaaS proposition into a clear landing-page narrative
- Building a responsive page without a frontend framework
- Organizing a large visual system with plain CSS
- Deploying a static website behind a custom domain

## Running locally

Open `index.html` directly in a browser or serve the directory with any static HTTP server.

## About this repository

This repository documents a learning project and the technical decisions explored while building it. It is not presented as a production-ready system.
